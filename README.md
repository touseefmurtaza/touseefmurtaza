## Hey, I'm Touseef 👋

I'm a software engineer from Lahore. I've been writing software for about eight years, mostly full-stack, and these days most of my time goes into LLM features that have to hold up in production.

Right now I'm at **Jobandtalent**, working on AI features for hiring and payroll: vacancy generators, screening agents, and the monitoring that tells us when they're getting things wrong. Before that I led the Fulfilment team at **Sendoso**, where we broke up the order monolith around Kafka and reworked our Salesforce integrations so they'd stop hitting rate limits.

I started out on Ruby on Rails, and a lot of the older repos here are from that period. Now I mostly write TypeScript (Next.js, Node), with some Kotlin, and Postgres underneath nearly everything.

**What's on here**

- [agentic-workflow-api](https://github.com/touseefmurtaza/agentic-workflow-api): a small Node API where I try out ways to plan and run multi-step agent workflows
- [ai-ticket-triage-next](https://github.com/touseefmurtaza/ai-ticket-triage-next): a Next.js prototype that sorts support tickets and drafts replies
- [react-ai-prompt-lab](https://github.com/touseefmurtaza/react-ai-prompt-lab): a scratchpad for comparing and scoring prompts
- [ai-engineering-playbook](https://github.com/touseefmurtaza/ai-engineering-playbook): notes I keep on shipping AI features without hurting yourself

These are early side projects. Right now the first three run on rule-based logic so they're cheap and predictable to work on, and wiring in real model calls is next. Most of my real work lives in private company repos.

**Lately** I've been setting up Claude Code with a handful of sub-agents (architect, reviewer, QA) that work in separate git worktrees, with me approving each step. It's made reviews faster without making them sloppier, and I'm still tuning it. I've published a version of it as [claude-code-agent-team](https://github.com/touseefmurtaza/claude-code-agent-team) if you want to try it.

I'm open to freelance and contract work, especially if you're shipping AI features and want someone who's done it before. You can find me at [touseefmurtaza.com](https://www.touseefmurtaza.com) or on [LinkedIn](https://www.linkedin.com/in/touseefmurtaza).
